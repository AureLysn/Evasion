# Quyết định — viết tiếp BCMF bằng **tiếng Trung**

## Chốt

- Văn viết tiếp: **tiếng Trung**, cùng ngôn ngữ với nguyên văn [[nguyen-van-zh-bcmf]].
- Đơn vị đo: **chữ Hán**. Chỉ tiêu đo thẳng trên nguyên văn — **không quy đổi**.

## Hệ quả

| | |
|---|---|
| Nguồn giọng văn | **chỉ** nguyên văn. Hai bản convert tiếng Việt **không** dùng để đo hay bắt chước — chúng là giọng máy dịch |
| Câu hỏi giọng tiếng Việt (ta / ngươi / hắn…) | **không áp dụng** — Aurel không chọn phương án nào, vì văn không viết bằng tiếng Việt |
| Tên riêng | viết theo cách **nguyên văn** viết: `沢田纲吉`, `工藤新一`, `首领太宰治`… — xem [[05_Evasion/01_Oeuvre/Studio/Continue/BCMF_bat-coc-mafia-cuu-vot-the-gioi/02_Story_Bible/style/hard-rules\|hard-rules]] |
| Công cụ | `style_metrics.py` đo chữ Hán được. `chapter_gate.py` chỉ đọc chữ Latin → chưa dùng cho BCMF |
