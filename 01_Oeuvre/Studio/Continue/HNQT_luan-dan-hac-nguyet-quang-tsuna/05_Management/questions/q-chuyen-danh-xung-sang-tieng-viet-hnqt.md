# Đưa danh xưng sang văn Việt thế nào?

| Nguồn | Phương án (chưa chọn) |
|---|---|
| 悟哥 | "anh Satoru" · "Satoru-nii" · "anh Ngộ" |
| 悟君 / 夏油君 / 纲吉君 | "Satoru-kun" · "cậu Satoru" · bỏ |
| 纲吉少爷 / 悟大人 | "cậu Tsunayoshi" / "Satoru-sama" · "thiếu gia Tsunayoshi" / "Ngộ đại nhân" |
| 十代目 | "Juudaime" · "Thập Đại Mục" · "Đệ Thập" |
| 殿下 (Basil) | "điện hạ" · "Sawada-dono" |
| 蠢纲 | "Dame-Tsuna" · "Tsuna ngốc" |
| 老头子 | "lão già" · "ông già" |
