# AureLysn — Evasion

The fiction zone of the AureLysn vault: story projects, the shared canon database, the reading
library and the tools built around them. It is a repository of its own, placed at `05_Evasion/`
inside the vault. Notes are written for Obsidian; most are in Vietnamese.

## What is here

| Folder | Content |
|---|---|
| `01_Oeuvre/Studio/` | Story projects, one folder per project (`<CODE>_<slug>`): overview, project canon, story bible, development, manuscript, management |
| `01_Oeuvre/Database/` | Shared reference: fandom canon notes, folklore, writing principles, research method, taxonomy of genres and tropes |
| `02_Library/` | Kệ Sách, a local reading app for a folder of books |
| `03_Subsystems/Nexus/` | TranslateCenter, a local translation and writing desk |
| `03_Subsystems/Pilot/` | Userscripts: downloaders, readers, translation helpers |
| `03_Subsystems/Verba/` | Chinese-to-Vietnamese conversion code |

Start from `_EVASION-MOC.md`, then `01_Oeuvre/_OEUVRE-MOC.md`.

## What is not here

- Book files (`.epub`, `.txt`, `.html`). The library itself is kept in cloud storage; this repository holds the reader and its settings.
- The Nexus dictionaries and staging files. They are large or temporary and are backed up separately. The Nexus database (`03_Subsystems/Nexus/data/library.db`) is in the repository; commit it with the app closed.
- The vault's contract, schema and checking tools. Links such as `[[AGENTS]]` or `[[09-gates]]` point to notes of the private vault and do not resolve here.

## Sources and credit

Several projects continue or cross over existing works, and the canon database summarises
published franchises. Those works belong to their authors and publishers. Source notes record
where each fact comes from. Nothing here is offered for commercial use.
